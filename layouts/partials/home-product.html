Complete infrastructure to run governed AI

Like an operating system, DSS gives you identities, memory, permissions, interfaces and an audit trail in one layer, rather than scattered across applications.

In an operating system In DSS
Users and processes Principals — people, runtime models, organisations and delegated agents
Memory and the filesystem Ledgers — append-only, versioned, git-backed memory boundaries
Applications and interfaces Surfaces — Chat, Decode and the Control Plane
File permissions and access control Grants — managed in the Control Plane and stored as versioned state
System log and audit trail Lineage — every entry keeps the entries it derives from
Drivers Model routing — many providers behind one interface, using your own keys

An analogy: it is not a kernel, it does not schedule processes, and it makes no real-time guarantee.

Principals Live

Every human and agent acts as a named Principal, with passkey and DID-based identity. Delegated agents are scoped to named ledgers and surfaces.

Grants Live

Grants are managed in the Control Plane and stored as versioned state.

Lineage Live

Entries record the entries they derive from. Walk the lineage of any entry with bounded, fast reads, and see what an answer drew on.

Coordinates Live

Records sit at prime-indexed coordinates; retrieval runs against an index rebuilt from the git ledger.

Ledgers Live

Ledgers are versioned and git-backed. New entries are added; prior versions stay readable; writes never force-overwrite history.

The advantage of a unified, structural layer

Identity, permissions, memory and agent workflows run as one layer, so what an agent did is a matter of record rather than of log-grepping.

Traceable by construction

Every entry keeps its parents and children. You walk back to the entries an answer used.

Grants you can manage

Principals, grants and access windows are managed in the Control Plane, and the models each principal can pick follow those grants.

Cross-checked, not trusted

Two independent services verify decode reports against a shared invariant checker; mismatches are refused.

Compounding structure

Each write adds relationships to the ledger. What the system accumulates is auditable because the index is rebuilt from the ledger.
